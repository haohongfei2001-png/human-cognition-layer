# TORQUE attribution

Qiang Ning, Hao Wu, Rujun Han, Nanyun Peng, Matt Gardner and Dan Roth. TORQUE: A Reading Comprehension Dataset of Temporal Ordering Questions, EMNLP 2020. https://aclanthology.org/2020.emnlp-main.88/

Official dataset https://github.com/qiangning/TORQUE-dataset at `ab27019cc6a317fde3c879900499f02acce8b16d`; repository Apache-2.0 license copied verbatim as `TORQUE_SOURCE_LICENSE.txt`. This initial package redistributes only source metadata/hashes and selection, no selected passage/question/answer text. Any later source-containing evaluation artifacts preserve attribution/source license separately from HCL code. No native event/answer annotation is a runtime input. News snippets are historical passage-relative narrative premises, not claims of current news truth or private psychology.
