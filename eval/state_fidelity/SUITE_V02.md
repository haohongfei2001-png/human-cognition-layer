# State Fidelity Suite v0.2

This suite is a fresh boundary set created **after** the first 12-case HCL v0.3 prompt iteration.

It contains 36 cases:

- 12 SIMPLE
- 12 EPISTEMIC
- 12 CAUSAL_AMBIGUITY

Purpose:

1. detect overthinking on explicit cases;
2. test false-belief and information-access tracking;
3. test second-order knowledge and missing evidence bridges;
4. test preservation of genuine hidden-cause ambiguity;
5. prevent overfitting to the original 12 fixtures.

The suite gates on structural semantics:
- mode;
- uncertainty level;
- hypothesis-count range;
- missing-bridge presence;
- optional field-scoped agent assertions.

Lexical substring checks are advisory only and do not determine pass/fail.
