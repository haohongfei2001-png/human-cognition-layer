# State Fidelity Suite v0.3 — Paired Boundaries

This is a fresh paired-boundary suite created after Suite v0.2 was observed.

It contains 12 minimal contrast pairs / 24 cases.

Each pair changes one decision-relevant fact while keeping the surrounding task similar. The purpose is to test whether HCL changes its internal mode and uncertainty for the **right causal reason**, rather than memorizing surface forms.

Boundaries tested:

1. truthful communication vs misinformation;
2. observed change vs unobserved change;
3. clearly heard announcement vs uncertain hearing;
4. explicit emotion vs emotion inferred from behavior;
5. explicit cause vs unexplained outcome;
6. explicit second-order evidence bridge vs missing bridge;
7. obvious joke vs ambiguous short remark;
8. explicit intention vs intention inferred from behavior;
9. explicit preference vs behavior that conflicts with prior preference;
10. read message vs unread message;
11. complete vs incomplete information chain;
12. explicit social motive vs ambiguous social gesture.

This suite must not be used to tune HCL before its first run.
