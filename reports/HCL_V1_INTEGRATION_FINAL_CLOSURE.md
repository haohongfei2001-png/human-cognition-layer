## Executable architecture

`hcl/v1/capabilities.py` registers 22 retained-core, optional-simplified, generic-tool and inactive assets with implementation, evidence, activation, dependency, cost and failure policy. `router.py` returns ordinary-task `CognitionPlan`, independent of benchmark identity. Factual tasks take the direct path. Knowledge/access questions select perspective/belief; goal and affect questions select optional source-grounded context. Exact computation requires typed declared inputs, not mined NL graphs. Missing assumptions generate system insufficiency. Deterministic low-overhead paths schedule no extraction/provider passes.

`context.py` supplies independently empty evidence, provenance, temporal scope, actors, perspective, belief, explicit intention, affect evidence, uncertainty, conditional tool results and unsupported-inference fields. Evidence vocabulary never promotes reports/actions/hypotheses into private truth. `layer.py` composes validated v0.6/v0.7/v0.8 assets and calls the replaceable base-model adapter once. Debug receipts expose the actual plan/context/messages; ordinary answers are plain text. `tools.py` dispatches source-scoped causal, Dung argumentation, equivalence, countermodel/witness and alternative-reading calculations without storing outputs as observations or beliefs.

Integration found and repaired an inherited boundary hazard: globally enumerated proposition names could enter an observer view with SYSTEM_INSUFFICIENT and no supporting IDs. v1 suppresses zero-support estimates, including hidden/future names; the composition test requires the private resignation proposition to stay absent. Existing frozen runtime source and historical assertions remain unchanged. Runtime imports exclude scripts/eval/reports/provider SDKs; no broad file moves.

Limits: rules have finite English/Chinese vocabulary; ambiguous subjects require explicit target/observer IDs; raw prose does not automatically yield validated access/mental state. Inject validated historical runtimes for committed belief/intention/affect state. v0.5 remains the persistence foundation upstream; v1 does not replace it. Context overflow fails closed instead of clipping evidence. A model-facing policy is not proof that an arbitrary model obeys it. Provider-free tests demonstrate correctness, not semantic extraction or external model utility.
