# Assistant-first UX v1

Home直接输入，无Case wizard。左栏新对话/搜索/历史/Topic，底部Settings/Advanced；中央自然聊天，右侧默认不存在。无HCL开关、Base/P/G/ablation前台主操作。

v1只有一个Topic容器，UI可称项目。People仅相关时出现，无强制profile。Files附当前conversation，明确选择后加入Topic，不全账户复用。顶部标题/Topic，回答级引用、Explain、更多。简单问题不显示认知步骤。mock阶段全局明确“模拟运行：未接入真实HCL机制”。

文件注册、可解析、已选范围、未覆盖分别显示。v1 TXT/Markdown/paste；未知格式/超限明确失败。引用定位当时版本且遵从当前权限；不把近似引用当exact；文档命令无记忆赋权。

Explain为轻量抽屉，关闭返回原focus。按问题展示已知信息、依据、替代、关键条件、缺口；不强制填满六栏。关键不确定性仍在正文。“这只是猜测/人物不对/时间不对/停止使用”进入RevisionCommand；旧answer不重写，按新信息更新为新run。默认零新调用，删除后不从缓存复活。

正常回答先实际判断，必要时关键条件与稳健行动。主判断可为“目前不能把未回复当拒绝”，不强选动机；也不能一律拒绝有据推断。来源以自然语言归属，用户情绪不机械否定。

记忆可看范围、已用背景、stop-using/delete；临时/conversation/Topic分开，cross-topic默认不开放。不是关闭HCL，而是HCL执行范围政策。

Lab入口Advanced→Lab，或回答更多→在Lab检查。Inspect显示同run显式状态，Lab展示执行/版本/失败；L2 Compare入口disabled、零provider；不写回生产context。图分dependency/execution，不称模型私有思维；无3D全图。

验收：文字状态而非仅颜色、keyboard/focus、窄desktop折叠而非挤三栏、stream恢复、stop/retry、明确错误不无限spinner；实际browser覆盖与未测分开，不以截图替代后端持久化检查。
