# D03 — Competing strategic communication explanations

## CAPABILITY_DELTA

Correcting a pre-statement belief changes the relative conditional support for
benign error and deliberate falsehood. A false statement by itself leaves both
unresolved. A literally true statement can coexist with separately source-grounded
concealment concerns when explicit omission, knowledge claim, goal and received
information need align. None of these checks proves actual deception or motive.

`prepare_strategic_communication` reuses C01 goals, B03 belief revision through
C03's prefix preparation, B01 knowledge operators, B02 receipt and A01/A02 support.
The utterance is source-bound to its speaker and named recipient. Reader truth
claims are retrospective evidence about that utterance, never speaker knowledge.
Speaker beliefs/goals/knowledge and recipient information needs are taken only
from the action prefix. Exact omission-to-statement binding avoids attaching a
vague omission report to an arbitrary statement. Negative belief is distinct from
not believing; knowledge claims remain separate from private belief. Contradictory
premises remain conflict, not majority or a unique winning motive.

B02 now admits explicit narrator statement-truth/omission records as reader
records; this grants no character access. Four candidate condition sets remain
separate in actual final input. The simplest alternative is a generic table of
these source premises; serious post-G-ARCH comparison should simplify this join
if it adds no observable benefit beyond that table.
