# Source-bound executable entry modes

The planner now receives the same code-generated source/version contract used
for admission. It states the B01/C01/C02/C03 modes and their necessary literal
syntax observations, and known B02/D02 source-entry blockers. These observations
are interface constraints, not source claims, semantic judgments or native
execution receipts. The model still interprets the user's task and constructs
faithful source-anchored semantic inputs in its original planning response.

The contract reuses the existing local candidate parser and family grammar. B01
requires a possible modal utterance; C01 requires an existing agency form; C03
requires a conditional-plan form. C02 requires a candidate literal event, which
is only an initial necessary condition: the actual action, actor, time and query
joins still belong to the original explanation adapter. Positive observations
do not guarantee native treatment, relevance or a successful final answer.
No native view is pre-run, no claim is created and no extra model call occurs.

For ordinary callers, a literal reader with no typed premise remains available
to return a genuine insufficient-evidence result. The planner sees that limit
and the semantic and insufficient modes. Mixed unavailable-operation receipts
and real results remain honest partial outcomes. The normal final answer still
requires an actual native result and all existing citation/source checks.

For an existing caller that explicitly requires checked native processing,
literal mode is unavailable when its necessary syntax is absent. Known B02/D02
blockers and unavailable ordinary adapters also prevent plan admission. The
entire returned plan is validated before any native operation; it is never
repaired by deleting a failed operation or generating replacement candidates.
The source/version snapshot is checked before and after planning as before.
The strict actual-native gate remains after execution, because syntax admission
cannot prove that treatment occurred.

All 40 retained capability IDs and families remain visible. The 14 callable
adapters retain their complete question, source, binding and result contracts.
Python implementation import paths and absent-contract null fields no longer
occupy planner input. Shared mode meanings are included once. A source_index
references the unchanged complete sources array, together with its version; this
avoids repeating long Unicode source IDs. The model's operation still uses the
original source_ids, and trusted validation resolves the index against the same
captured source array. Complete original
sources and the 36,000-byte request guard are preserved without truncation.

The contract depends on the source, source version and caller's ordinary versus
checked-processing requirement. It does not read case IDs, answers, gold labels,
scoring rules or requested target families. It cannot make HCL understand
arbitrary natural language, make model translations correct, or guarantee that
the model follows the contract. Rejection before unnecessary work is a control
property, not evidence of improved model selection.

Provider-free controls include independent speech, dialogue, narrator, negation,
uncertainty, agency, action-time and conditional-plan inputs; actual native
positive/negative replay; source revisions; forged metadata; ordinary limited
answers; eight-source Unicode IDs; and requests near the previous no-hint wire
boundary. Real model effectiveness requires
a separately approved evaluation. No model budget, grant or trigger is created.
