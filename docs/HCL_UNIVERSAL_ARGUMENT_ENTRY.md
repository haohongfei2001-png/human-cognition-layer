# Bounded G04 integration into ordinary HCL entry

This provider-free batch makes the retained `ArgumentWorkspace` available to
internal selection. Nine of 40 catalog packages now have bounded ordinary-entry
adapters. Full A–H integration, model selection quality and answer benefit remain
incomplete/unverified. No provider invocation, spending or permission change is
part of this batch.

## Complete source, original question and conditional argument mapping

G04 takes exactly one selected complete source and the unchanged original user
question. Planner rewrites/bindings cannot supply premises, challenges, concept
readings, priorities, timestamps or authority. Multiple sources require separate
operations and are never merged into one actor/context domain. Every original
source, including unselected sources, still reaches the final answer input.

The retained bounded grammar maps source-reported arguments and up to three
premises per argument; exact narrator reports and explicit challenges; source-local
concept readings; explicit opposed value rankings; targeted counterexamples and
proposed analogies. A challenge does not prove a premise false. Reported premises
and conclusions are not verified world truth. An argument map is not a logical
proof; analogies do not transfer conclusions. No winner or moral verdict is
selected. Unsupported forms and unmatched premises remain unresolved.

This adapter preserves the retained bounds: 16,000 source characters, 64 source
lines, 4,000 question characters and the retained 32,000-character serialized
preparation budget. An oversized source/question or expanded result is rejected
without truncation or a false execution claim. A successful preparation can still
contain zero parsed arguments or zero disagreements. Counts and successful
execution do not certify substantive treatment or semantic understanding.

## Explicit-negation correctness repair

The retained opposition helper previously removed ` is not ` without checking
whether it occurred. Consequently identical affirmative conclusions such as
`choice is free` were incorrectly classified as opposed, yielding a false
two-speaker disagreement. The minimal repair requires the removed negation to be
present. Supported leading `not ` and infix ` is not ` forms remain symmetric;
identical affirmative and negative claims do not oppose themselves. No antonym,
world-knowledge or arbitrary-language inference is added. Different premises or
value priorities alone do not turn identical conclusions into opposed conclusions.
Existing positive and historical witness inputs are retained unchanged.

## Shared source support and revision

The temporary workspace uses the actual selected source ID, entire text,
recorded ingestion time and current shared version, including revisions above
one. Exact quotes, offsets and line order remain in the payload. Internal
line-span IDs remain local to the retained payload; they are not individually
imported shared graph nodes. The whole conditional result is supported by the
selected full-source root in shared EvidenceCore, including negative/empty
findings. Source correction or withdrawal invalidates that result; withdrawal
of the operation support blocks answer delivery. Unrelated source changes do
not invalidate the individual claim. Universal orchestration still refuses any
input revision during planning, preparation or answer delivery.

The adapter exposes only the current whole-source view, without inferred actor
access, historical line prefix, event time or calendar time. The direct retained
G04 API keeps its separately tested observer/time/prefix views. Historical
snapshots retain their original source versions and are not rewritten.

## Immutable evidence and validation

Three runtime files change: the opposition helper, dispatch and catalog. The new
runtime amendment pins every prior amendment script/report byte-for-byte and
reconstructs the exact previous G03 runtime using only those three old file
hashes. It also validates the consumed archive chain through v24/DRC008. Older
live-tree validators remain immutable; current callers use the new validator
because earlier restoration code predates the additional retained-file change.
Tamper tests cover oldest and latest chain nodes, changed and unrelated runtime,
and current digest drift. Existing historical receipts, runtime archives, paid
execution freezes, grants, reservations and private outputs are untouched.

The synthetic witness records actual scripted orchestration/final messages,
source correction invalidation and the identical-conclusion regression. Direct
and adapter tests cover explicit opposition, premise/challenge/concept/value
mapping, source-domain isolation, shared revisions, empty/unsupported input,
source/support withdrawal and bounds. These are provider-free correctness
checks, not model planner efficacy, answer gain or complete family integration.
Both historical grants remain closed. No new live workflow, retry, provider
switch, spend or final-confirmation access is authorized by this change.
