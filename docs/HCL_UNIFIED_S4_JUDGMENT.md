# S4 conditional normative and value judgment

This is an INTEGRATED_OFFLINE_PARTIAL implementation of approved M14. It keeps
S3/S4, M14 and T17/T18/T19 open. Ordinary Chinese and English source material
passes through the same authenticated `HCL.run` entry, using an offline port to
inject source-bound candidate interpretations. These examples establish local
computation and consumption, not open extraction accuracy or moral truth.

## Finite executable contract

`judgment.evaluate` proposes `hcl-judgment-candidates-1`, compiles it through
`judgment-model-1`, and uses `LocalModelOperator.run(snapshot, issue, allowance)`.
The compiler rejects precomputed permission, recommendation and score fields.
Every fact binding, value dimension, norm, framework origin and assumption has
original source spans; question text cannot serve as evidence. Declared origin
separates reported user adoption, reported personal endorsement, institutional
statements and analyst-conditional frameworks. None authenticates a current
user preference or grants system authority. M03, M13 and framework frame kinds
must agree; unimplemented cross-frame bridges are rejected.

The first contract permits finite **single-step** action graphs only. Each
choice retains the source's action-time actor and actual M03 possible states.
There is one real shared M03/M05 execution; M07 consumes that same cognitive
execution and computes its commitment lifecycle. Knowledge uses actual truth
and belief together. World control opportunities come from actual M05 state
feasibility, separately from subjective enablement and scalar Q ranking.
Commitment conditions consume M07 output. Optional causal factors consume M06
output. These factors remain distinct: a belief, opportunity, promise breach
or causal contribution is not by itself private intention or blame. Later
receipts cannot rewrite earlier action-time knowledge.

Computed facts qualify source-anchored M13 premises, then the real proof,
defeat, grounded and bounded preferred-extension algorithms run. UNKNOWN
facts are never inserted as false. A conservative dependency closure follows
positive/contrary literals, rule conclusions and undercuts, keeping affected
norm and responsibility queries unresolved even if dropping an unknown premise
would otherwise make its opponent win. Unrelated queries remain usable. Norm
branches use complete extensions of one joint theory; independently marginal
norm labels are never combined into fictitious extensions.

Each framework separately distinguishes physical infeasibility, prohibition,
unresolved permission and permission within the stated finite constraints.
An unresolved possible constraint cannot grant permission for an action that
would violate it. An action satisfying every retained possible constraint can
still receive a positive recommendation. This is conservative conditional
permission, not exhaustive proof of real-world permissibility. Hard constraints
cannot be compensated by higher utility.

## Exact value calculation and dissent

Each action's full consequence vector is computed from the **same action and
same successor transition** in each joint scenario. Exact rational probabilities
and values use Fraction arithmetic. Single-scenario EXPECTED comparisons retain
all exact ties. Missing probabilities do not become uniform beliefs: retained
possible states become separate uncertainty scenarios. EXPECTED stays unresolved
when a joint distribution is unspecified. Explicit scenarios are hypotheses
whose support must be within the actual retained M03 states.

Unknown weights produce a genuine non-dominated frontier and pairwise linear
weight conditions; there is no uniform-weight default. With explicit weights,
joint scenario comparisons retain pairwise differences and worst differences.
MAXIMIN first sums weighted dimensions *within each scenario*, then minimizes
across scenarios, then removes weak-maximin ties that are dominated. It never
splices independent best Q dimensions or independent worst dimension values into
an impossible vector. Multi-step policies are rejected rather than approximated
with separately optimal component policies.

Recommendations retain rival options, per-dimension costs, foregone benefits of
excluded actions, excluding norms, preferred-extension dissent, and factual and
principle dependencies. Weights/scales, priorities and facts can be changed and
recomputed independently; unchanged cognitive/commitment results are tested.
Concept meaning and scale choice remain explicit hypotheses. The additive
[v2 concept consumer](HCL_UNIFIED_S4_CONCEPT_JUDGMENT.md) implements finite joint
version interventions; open conceptual-sensitivity search remains unimplemented. If supplied frameworks or joint extensions
disagree, the overall recommendation is their intersection; individual
conditional conclusions and the needed value/principle choice remain visible.
This allows actual positive recommendations without manufacturing a winner.

## Durable delivery and bounds

The result and candidate Delta share the ordinary task ledger, read_set, ACL
epoch and one commit identity. Certificates replay all actual upstream and
joint-choice computation. They also reconstruct the original raw candidate,
source segments, exact source hashes, offsets, versions and host-created source
bindings before compiling again. Recommendation, dimensions, adopter,
source/version, nested upstream values and assumption/premise mutations fail
before delivery. Claims bind actual facts, feasible sets, frontiers,
recommendations, dissent and revision conditions. Certificates confer no access;
fresh runtime ACL and source-dependency checks still gate every delivery.

The compiler bounds four models, four decisions and four frameworks per model,
eight value dimensions, sixteen scenarios, sixteen norms per framework and
thirty-two factual factors. Existing M03/M05/M07/M13 bounds additionally apply.
Work units charge shared upstream work, mapped-state planning, factual queries,
joint outcome dimensions, score and dominance comparisons and alternative costs.
They are algorithmic units, not elapsed CPU time. An exhausted prefix is never a
complete frontier or recommendation; even if an earlier framework completed,
its incomplete decision is withheld from recommendation delivery.

RETURNED, computed and committed recovery preserves original accepted effects
without new sends. UNKNOWN retains its reservation and refuses automatic resume.
