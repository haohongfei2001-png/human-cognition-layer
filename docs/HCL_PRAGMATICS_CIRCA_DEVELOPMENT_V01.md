# Frozen pragmatic interpretation development method screen v01

## Capability and method

Interpret an indirect conversational reply in its actual situation and in relation to the preceding question. hcl/pragmatics.py offers a reusable thin reasoning procedure: separate literal content and supported communicative implication; compare possible readings; retain conditions/hedges; refuse unwarranted private mental certainty. Its source_view preserves exact context and X/Y utterances while ignoring annotation and rewritten hypothesis fields. It does not deterministically infer meaning, commit beliefs, judge moral truth, build a new ontology or establish novel cognitive architecture. Its efficacy is unmeasured until this source experiment; tests certify only source/request invariants. Both C and P are competent full-context model methods, same input and output budget.
