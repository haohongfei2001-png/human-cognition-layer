HCL run/run_sync/stream engine, exact context compiler, model gateway, durable
execution graph, shared budgets, commit qualification, answer-field consumption
and recovery. It adds a typed `mental-scene-1` LocalModel dialect. No persisted
class or old wire field changes. No second state store or answer-only endpoint.

The source and question stay ordinary Unicode. The model port proposes anchored
agents, Boolean variables, event effects/observation channels, action graphs,
utilities and structural equations. It cannot supply computed beliefs, Q values,
chosen actions or solver labels. JSON fields, byte/resource limits, declared
identities, source spans, causal rule excerpts, event order and all observation
channels are checked. Query anchors are never used as factual event evidence.
Unaccounted source segments fail compilation; explicitly unmodeled segments
remain visible and keep the result partial.

The installed port is still an offline test fixture. Its proposals are conditions
under which algorithms run, not a natural-language extraction implementation or
independent semantic alignment proof. An executable, source-anchored hypothesis
can still misinterpret its source. Every result is explicitly conditional and
candidate completeness remains NOT_ESTABLISHED. Contrasting model inputs must
change actual computed results, not select pre-encoded answer samples.

## Finite mental worlds and events (partial M03)

`operators/epistemic.py` represents actual designated states separately from each
agent's directed accessibility relation. Event-product update computes simultaneous
world effects and per-agent event alternatives. A hidden physical change updates
the world while an unobserving character retains the old view. Private messages
separate received, understood and trusted channels. An accepted message changes
the receiver's view, not the actual world, and does not grant other agents common
knowledge of receipt or acceptance. The model can represent mistaken belief.

Nested belief formulas are evaluated over actual successor relations; outer
negation and negated content are different trees. Empty views return explicit
inconsistency/unknown instead of vacuous certainty. Exact reachable-state
bisimulation merges only modal-equivalent states, preserving every agent's
successor classes, including empty views. World counts never become probabilities.
This controls repeated-event growth without an approximate truth claim.

The ordinary-source compiler currently supplies independent Boolean initial
alternatives with declared initial observation channels and a total finite event
order. It does not yet supply arbitrary initial constraints, ambiguous temporal
branches, forgetting/attention alternatives or a persistent incremental mental
index. The pure solver supports explicit finite directed relations; this is not
an unrestricted model language or logical-omniscience claim about real people.

Timeline queries use events only up to the requested model time. An analyst's
later record has no character effect without a modeled receipt/observation event.
Model and event assumptions propagate into at-time results/shared variables.
Withdrawing a necessary assumption removes that prediction; future evidence
cannot overwrite an earlier character-access state. A new source revision makes
old cached dependencies stale; a new request computes the revised model.

## Action values from the same remaining states (partial M05)

`operators/agency.py` computes exact finite-horizon belief-state dynamic
programming over declared actions, transitions, observation symbols, costs and
terminal utilities. Posterior branches depend on what the agent can observe,
not on hidden actual state. It returns actual Q values, ties and subjective
versus world feasibility. The action calculation consumes the exact remaining
states from M03 under a stable source/model/actor/time variable ID.
The shared variable retains only raw M03 alternatives. Each plan has its own
explicit Boolean state-codebook mapping and mapped belief; answer validation
rechecks that mapping against the shared worlds. Two plans cannot overwrite each
other's cognitive dependency just by using different state names.

If more than one planning state remains, the engine requires an explicit
normalized rational distribution. It never invents uniform or calibrated human
probabilities. A declared mixture combines computed softmax action values with
habit and error policies; inferior actions can be predicted without rewriting
them as optimal. Opportunity availability, feasibility and terminal states stay
separate. There is not yet inverse goal inference, unique evidence-factor
registration, residual-guided model discovery or identified motivational change.

## Causal observation, intervention and retraction (partial M06)

`operators/causal.py` reuses only the existing pure `hcl.v09.runtime.CausalModel`
Boolean DAG evaluator. It does not instantiate the old runtime or import old
cognitive state/grants. It enumerates background assignments compatible with
factual observations, replaces intervened mechanisms, and predicts downstream
values. Observation, `do` intervention and evidence withdrawal are distinct
operations, independently compared with hand-enumerated Boolean worlds.
Results retain the proposed equations, original assignments, traces and
conditional identification status. No causal discovery or real-world causal
certificate is inferred from source grounding or successful computation.

## Bounds, durable behavior and precise migration

Current compilation caps include four candidate models, eight Boolean variables,
eight agents, 32 events and queries, eight plans/causal queries and planning
horizon 16. Runtime profiles bound finite worlds, relation edges, formula depth,
world-evaluation work and planning expansion. The execution budget counts local
solver batches, each with explicit internal bounds; it does not pretend that a
batch is one CPU instruction. Resource exhaustion retains frontier/unknown and
never a fabricated Q/mental conclusion. Full traces remain in the persisted
inference; delivery consumes exact compact nested fields and honors the complete
TaskResult byte limit. This is not an S6 capacity or latency claim.

Existing fresh ACL checks, immutable snapshots, actual committed-operation hash
eligibility, unknown-send holds and explicit owner recovery remain in force.
Known RETURNED responses survive restart without a new send. Revocation at late
delivery clears all source/derived outputs; replay checks current permissions.

An explicit side-copy adds only the exact shipped S2.3 runtime bundle
`badb3f7745a21193f199c4224847ccc931e4079e1d545c17825762b651d2404f`
to the predecessor allowlist, alongside unchanged S2.2. The predecessor consists
of exactly 168 hashed runtime Python files from main #429. Old codec bytes,
objects, events, calls and graph checkpoints retain their meaning. Current open
still refuses an old controlled store directly. Old writers are fenced before
publication; unpublished paths cannot execute. Unknown hashes, incompatible
indexes, relocated/readonly controls and disagreement between schema4 controls
remain rejected. Tests use real old runtime projections, never patched grants.
