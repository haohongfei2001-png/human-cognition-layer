# S3 conditional relationship and longitudinal-model increment

This is partial offline M09 evidence through ordinary authenticated HCL entry.
It does not close M09, T11/T12/T27, S3, or any other approved S1–S7 research exit.
An injected proposal supplies source-bound experimental hypotheses, not answers,
trust scores, Q values, fitted change points, verified extraction or private truth.
The complete formal mechanism and acceptance obligations remain authoritative.

## One actual cognitive execution

`relationship.evaluate` compiles `hcl-relationship-candidates-1` into the common
LocalModel protocol. Every proposed relation, hypothesis, likelihood, role,
identity report, observation and prediction mechanism requires SOURCE spans.
Question spans cannot supply facts. Duplicate fields, unknown fields, supplied
scores/results, mixed longitudinal actors and retrospective forecasts fail the
input gate. Each model has one common mental program plus M07 interaction fields
and M08 episode/channel fields. Existing compilers validate both domain inputs.

M07 recipient-specific interpretations are applied to one real M03 event product,
with the union of the interaction, appraisal and relationship query times. M07
and M08 consume that same immutable operation, actual perspectives, source
versions and assumption environments. Identical variable names alone are not
accepted as proof of shared state. An internal ephemeral composition value binds
the original input, authenticated Snapshot, Delta, read set, rule and access epoch;
it is not a candidate-constructible capability or a second state store. M03 work
is charged once and all further domain work consumes the shared remainder.

The resulting actual M07 commitment histories and actual M08 appraisals/coping
branches feed relationship and action predictions. A message reading different
from its literal content changes both downstream domains together. A withdrawn
event assumption or world/work frontier leaves dependencies unresolved; it cannot
be silently replaced by the raw source event or an omniscient fallback view.

## Directed relationship hypotheses and history

Relations are indexed by observer, target, domain and ABILITY/GOODWILL/RELIABILITY.
No reverse-direction or cross-dimension update is implied. Each has a finite
source-declared hypothesis set and either an exact normalized prior or no prior.
Updates require an actually applied event, receipt/understanding or observation
by this observer, and a condition computed in this observer's current M03 view.
An optional commitment-status dependency is read from the actual M07 lifecycle
at or before the update time, including a breach followed by later fulfillment.
A known absent receipt or false condition is inapplicable; unfinished computation
is unresolved. Neither becomes favorable evidence merely because a proposal
contains a likelihood table.

Exact likelihood multiplication is conditional on an explicitly declared
CONDITIONAL_INDEPENDENCE_MODEL hypothesis. That assumption is retained in the
result and final claim environment. It is not statistical evidence that the
reports are independent or that numbers measure human trust. Without a prior,
zero-likelihood hypotheses are excluded but no equal-weight distribution is
invented. All-zero support is MODEL_CONTRADICTED with visible PARTIAL qualification.
The same observer/event-time/source-span factor is applied once despite display
aliases. Conflicting likelihoods for the same factor retract only that factor
from the current calculation, preserving other factors and all earlier rows.
Unresolved reports can become eligible later without rewriting the original row.

A relationship-responsive action mechanism may transform goal priorities using
its declared hypothesis-specific multipliers. Known conditional weights compute
an expected multiplier; unknown weights retain separate compatible hypotheses.
This is a declared priority-response model, not an inferred joint posterior across
relationships. Each context uses only history available by its event time.
Unresolved, conflicting or unprocessed dependencies prevent a qualified prediction.
Independent mechanisms remain usable when one relationship model is contradicted.

Receipt, apology acceptance, forgiveness and restored trust are not synonymous.
There is no automatic apology-to-trust transition here. Dedicated semantic
acceptance evidence, richer repair causal models and calibrated effects remain
research work under the original M09 requirements.

## Roles, identities and actual action predictions

Role requirements, SELF_IDENTIFICATION, OTHER_ATTRIBUTION and source-observed
actions are distinct records. A role applies to a declared actor, time range and
real appraisal episode; its condition is evaluated in that actor's M03 view.
The solver enumerates unresolved applicability branches, intersects requirements
with supported subjective action opportunities, and searches bounded minimal
incompatible role sets. A common feasible action is an explicit reconciliation;
missing world/computational information is not a fabricated role conflict.
Designated-world views remain separate from subjective opportunities. Self-report
and another person's identity attribution do not become role constraints or an
inferred private identity verdict.

Each mechanism specifies normalized goal priorities or an actual M08 coping
alternative, goal multipliers, role sensitivity and optional relationship effects.
Actual coping changes include considered actions, the existing observation
coarsening, planning horizon and appraisal-conditioned priority history, not just
its descriptive label. Real M05 computes finite-horizon Q and possible best
actions from those conditions. Values are never accepted from candidate JSON.
The current finite response model restricts actions to the context's supported
subjective opportunities; it does not claim unrestricted future opportunity
acquisition. No available feasible action is a computed empty-action outcome,
distinct from an uncomputed prediction. Unknown belief probabilities, undefined
priorities, unsupported derived rationals and unfinished planning retain explicit
frontiers. Forecast rows are hypothetical and occur after the observed series.

## Longitudinal comparison and future consequences

The first algorithm is bounded segmented-path expansion over real prediction
cells. It evaluates every affordable zero-change mechanism before expanding
switches, retains stable priorities with changing knowledge/opportunities and
role/appraisal/relationship-sensitive competitors, and forbids switches between
simultaneous observations. It does not choose a value-change label from matching
text. Contexts are isolated by actor; source context names are declarations, not
certified independent situations.

Fit uses the shared M04 prediction comparison, correlated-factor profile and
Pareto frontier. Repeated source reports do not create extra independent support.
Full paths are regrouped by evidence factor, rather than adding prefix scores
that could double-count a later report. Exact mechanism presentation aliases are
coalesced, but semantic goal/hypothesis dictionary keys are retained. Structural
complexity counts actual declared parameter structure and segments; it is not a
psychological prior. No prefix is eliminated merely because its current fit is
worse. Capacity and work exhaustion retain unexplored paths and explicitly deny
a globally preferred model claim.

Preferred explored trajectories retain their change-point candidates and point
to actual future predictions under their last mechanism. An observed counterexample
can therefore change both the retained segment alternatives and future action
predictions without overwriting the observations, earlier relationship rows,
role requirements or cognitive history. A single observed choice never establishes
a stable trait, and every result remains conditional on this finite library.

This increment implements finite declared mechanism comparison, exact point
parameters and null-prior support. General parameter intervals, a no-parameter
argumentative variant, open residual-driven M09 mechanism synthesis, narrative
reliability/identity alignment, richer strategy/value opportunity models and
M11/M14 integration remain in the full plan. They are not renamed as completed
because this finite algorithm passes.

## Qualification, persistence and resource limits

The final consumer reconstructs the complete finite composition from its immutable
inputs and verifies the actual cognitive operation, M07/M08 results, relation
history, role solutions, all M05 predictions, fit/complexity, turns, qualifications
and assumption environments. Its pure certificate context cannot authorize a
source read or commit. The surrounding engine's current ACL/read-set, atomic
commit and delivery-capacity gates remain authoritative. Claims reference exact
committed fields. Nested domain issues and local frontiers remain visible and
make delivery PARTIAL even when another branch is completely computed.

There are at most four models, sixteen relations, eight hypotheses per relation,
thirty-two updates per relation, eight roles, thirty-two identity reports,
sixteen observations and sixteen forecasts, eight mechanism alternatives and
256 retained search states. All inherited M03/M05/M07/M08 limits apply. Local
work, call and output allowances remain shared. Relation response combinations
are capped at 32, composed prediction branches at 64. Multi-packet requests fail
before sending with RELATIONSHIP_COMPOSITION_CAPACITY; cross-packet longitudinal
compilation is not claimed. RETURNED, computed and committed recovery reuse
accepted durable operations without a new model send. UNKNOWN occupancy is not
released or reported as zero. Current source revocation governs cached delivery.

Fresh top-level LocalModel effect identities include their immutable Delta
session/principal, access epoch, rule and packed positive/query dependencies.
An ACL expansion or revoke/regrant can therefore create a newly authorized
effect for the same Issue without colliding with an old epoch. Pure nested
M03/M07/M08 IDs and all historical objects remain unchanged; accepted durable
operations are not rewrapped on recovery. Base revision is deliberately excluded
so unrelated appends do not destroy exact same-context reuse. The existing
commit guard still checks complete effect bytes, dependencies and current ACL;
an identity is not an authorization capability.

## Commitment-dependent evidence qualification

A M07 bookkeeping status alone cannot establish a relationship update. Unknown
fulfillment or an earlier uncertain latched activation can preserve several
lifecycle states even when the original prefix label says ACTIVE or
CONDITION_FALSE. The current producer consumes the actual M03 queries and
receipts, keeps that original history, and qualifies the entire prefix using
bounded Boolean marginal completions under the original lifecycle rules. This
is a conservative Cartesian overapproximation, not joint-trajectory inference.
Only an exhaustively settled matching condition can permit an otherwise
established likelihood factor. An unresolved prerequisite is recorded and does
not change the posterior as if it were evidence; dependent predictions remain
unresolved. Known independent false prerequisites remain inapplicable.

The existing metered condition unit covers the bounded prefix check; each
uncertain completion consumes another shared local unit. Unfinished enumeration
cannot certify its visited subset. Expanded/unresolved factors retain status
possibilities, completeness/work, assumptions and a reference to their unchanged
actual M07 original terms, fact queries and history. The final claim displays
these qualifications. Existing fully definite factor values and accounting are
retained. As elsewhere, these units are not a complete CPU-instruction count.

The six-case qualification witness exercises false/true/unknown fulfillment,
uncertain historical activation, budget and revoked replay. Tests also execute
the exact pre-fix PR436 189-file runtime projection: its known certificates still
validate, while its wrongly established unknown-fulfillment posterior cannot be
consumed under current qualification. Historical objects remain byte-identical.
Cached relationship deliveries, including enclosing claims referencing an actual
relationship record, pass the current pure certificate gate before the final
fresh ACL and capacity gate. An old numerical result that needs different
computation fails closed; it is not relabelled as current or rewritten in place.
A fresh request can recompute from the authorized source under the current
mechanism. No provider send or computational effect occurs during certificate
verification. These are synthetic compatibility fixtures, not a claim that the
pre-fix unpublished runtime acquired current authority.

The additional qualification has a real delivery cost. The original large
five-episode unknown-history probe crosses its unchanged 1 MiB final-delivery
limit and returns DELIVERY_CAPACITY without a claim; the same source with an
explicit 4 MiB output allowance returns PARTIAL with the full qualified proof.
No output limit, old runtime pin, evidence factor, or downstream assertion is
relaxed to force a passing result. Full M09 and all research targets remain open.

The qualification consumer replays only genuine M07 query instants through the
requested evidence time. The finite timeline includes all declared mental events,
acts, offers and deadlines. A consumer timestamp between those instants retains
the preceding prefix; it does not create a new query-less lifecycle row or claim
that absent query data establish `CONDITION_UNRESOLVED`. Unknown genuine query
marginals still require the bounded conservative completion described above.
