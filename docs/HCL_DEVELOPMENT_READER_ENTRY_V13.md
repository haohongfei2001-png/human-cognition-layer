# Generic ordinary reader entry after DRC001

## CAPABILITY_DELTA

HCL can now take an ordinary short reader question without a prearranged sentence
and pass existing B01 source-reported mental expressions, C01 goal/plan/opportunity
and C03 belief/model condition checks into its actual final messages. Previously
such questions entered a generic unsupported-scope wrapper even when the source
contained supported literal evidence. This reuses existing mechanisms; no new
ontology/module, inferred private state or claimed answer gain.

Failure is falsifiable: an arbitrary reader question plus supported source should
retain the whole source and deliver those bounded checks. The simple alternative
is Base with the complete source. Simplify/remove this integration if new fresh
checks show no benefit worth cost; do not preserve it by tuning consumed labels.

## General implementation and limits

`prepare_person_context` delegates unmatched short READER_ANALYSIS queries to the
same complete-source local preparation already used for long text. Exact supported
questions and argument comparison keep their prior routes. Preparation depends on
source evidence, not benchmark IDs, native choices/gold or guessed focal actors.
Private character/observer fallback remains closed even with narrative_access=True
without a source-validated private route. Generic questions cannot silently adopt
caller normative premises; explicit conditional responsibility scope is required.

Source narrative reports remain wrapped, not subject own speech/private truth.
Outcome/causality/narrator facts do not establish knowledge, intention, moral truth
or world feasibility. Explicit source statement prefixes exclude later statements
before preparation; order is not calendar time. Correction updates dependent local
plan conditions. Empty/unmatched prose stays complete with treatment=false, not a
fabricated mental state. Preparation-budget failures drop the whole local analysis
and record the failure in bounded refusal; no partial claim truncation.

This remains a **literal source-language coverage boundary**. It does not yet turn
implicit everyday prose into certified belief/access factors. It does not solve
all SimpleToM/SocialIQA tasks or establish broadly useful human cognition.
