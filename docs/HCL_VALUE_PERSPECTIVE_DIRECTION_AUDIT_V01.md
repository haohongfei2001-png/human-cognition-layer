Use only exact situation, action and one unlabelled character description, with question scoped to public source.

Equal endorsement does not universally imply real-world indecision; do not build that benchmark convention into a deterministic HCL solver. Exposure to challenge does not imply revision. Explicit current/past priorities can constrain an answer while leaving alternatives unresolved. Psychological discomfort is out of scope because constructed discomfort labels do not establish real affect.
