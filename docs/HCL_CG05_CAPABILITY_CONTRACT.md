## CAPABILITY_DELTA / minimal brief

HCL can now distinguish source-expressed meanings of the same social concept
by speaker and context, check a particular item against each local reading,
retain explicit counterexamples, and revise only a source-referenced definition.
For example, Alice uses `fair` for transparent decisions with consent; Bob uses
it for consent alone. Missing transparency evidence leaves Alice's reading
unresolved even when Bob's criteria are met. Neither reading becomes shared
meaning, moral truth, deception or a psychological diagnosis.

- Falsifiable failure: collapse speaker-local definitions into one meaning;
  infer missing properties; transfer another actor/context's exception; or let
  a later revision rewrite an earlier actor's accessible meaning.
- Simplest alternative: a prompt retaining an ordered table of definitions,
  source properties and explicit applications, without a specialized checker.
- New mechanism: validate complete source expressions; project actor/time/access;
  execute criteria and counterexample checks separately for every definition;
  perform explicit local supersession; preserve unresolved competing readings.

  substantial reverse boundary harm deactivates it; measurement failure is
