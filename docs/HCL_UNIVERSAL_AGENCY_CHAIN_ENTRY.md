# Retained C05 conditional chain in ordinary entry

Ordinary HCL planning can select the existing C05 chain for one complete source:
`Why did <Actor> <action>, considering their plans and appraisal of <episode>?`
The actor is one capitalized token, the action at most300 characters, the episode
at most160, and the internal question at most8,000. It remains an interpretation
of the unchanged original task, not a source premise. Actor bindings are unused.

The adapter uses the existing shared workspace, validates native current messages,
and forwards the entire payload/policy and every support claim ID. It does not
replace the workspace, migrate caches, change native parsing or add extraction
providers. Missing action remains insufficient even when current plans or
appraisal produce other claims. Checked treatment requires the native checked
conditional-chain status and nonempty explanations.

## Earlier action and current state

The source prefix used for action-time reasoning stays distinct from the current
source projection. A later belief reversal can change current feasibility while
leaving an earlier conditional explanation unchanged. Correcting the prior belief
can weaken that explanation; absent or other-actor belief remains unresolved.
Declared-model contradiction is not character knowledge or knowing infeasibility.
No unique motive, actual private emotion or moral truth is inferred.

Derived prefix workspaces are native temporary calculations. Their bridges are
anchored to exact spans in the original source and its shared current revision;
they do not become independent sources. Forwarded support IDs include the prefix,
current-plan, appraisal and joined-explanation obligations. Withdrawal after
preparation blocks answer admission; mutation during answer discards delivery.
Source order is an explicit assumption, not verified calendar chronology.

The canonical nine-line fixture performs five local full-source semantic
preparations and two derived-prefix preparations on the existing workspace.
Optional SemanticWorkspace caching can reduce the first count to one with an
identical native payload, but this batch does not change global lifecycle or
caching. Every preparation here is provider-free. Counts describe that fixture,
not a new allowance or a guarantee that missing-action cases run the same steps.

## Bounds and complete composition

The inherited limits remain one matching action episode, at most two
source-supported goal explanations linked to selected plans for that action,
16 accepted agency/belief rows, and20 explanation/appraisal source rows. Three
bare goals are not automatically three goal explanations. Repeated actions,
unsupported query forms, excess native bounds and multiple selected sources
remain explicit refusals. Other supplied outer sources remain in final input.

The combined C04-to-C05 witness carries both complete native payloads on shared
support. Its initial full requests measure22,518 bytes planning and27,354 bytes
answer. After a later belief reversal they measure22,624 and29,164 bytes. Exact
original-source citations pass location validation while semantic correctness
remains unassessed. The three-operation C04/C05/C05 witness exceeds the unchanged
36,000-byte request bound and stops before answer invocation, retaining all source
and operation data without truncation.

These are scripted interface checks, not evidence that a model selects the right
chain or produces better answers. Future live packages must freeze their own
complete requests, model settings and budget. No old grant is reopened.
