# Bounded G01 integration into ordinary HCL entry

This provider-free batch follows the canonical retained-capability integration
queue. It exposes an existing mechanism, not a new normative reasoner. Internal
planning can now select G01 alongside the six existing ordinary-entry adapters.
Seven of 40 catalog packages have bounded adapters; integration remains partial.

## Original request is a conditional input, not world evidence

The retained G01 interface already accepts an original user question without any
source document. Its bounded rule grammar can prepare an explicitly supplied
analysis condition. Universal entry previously returned SOURCE_PREREQUISITE_UNAVAILABLE
before every source-free dispatch, concealing that existing G01 ability.

The adapter now runs G01 before the generic source prerequisite. It passes the
unchanged original user question, never the planner's rewritten question or an
analyst-adopted framework argument. Selected source reports remain separate from
USER_SUPPLIED conditions. ANALYST_PROPOSED_UNADOPTED suggestions cannot become
executable conditions. The existing grammar and interpretation limits remain;
this is not semantic certification of arbitrary language or user intent.

An exact original-request span is a distinct EvidenceCore root. Its hash, span ID,
character extent and ORIGINAL_USER_REQUEST origin are carried beside the result.
The root supports a CONDITIONAL_TOOL_RESULT, not a SOURCE_REPORT. It is not added
to supplied-source citations or advertised as factual evidence. Selected source
versions and all dependency roots are checked before and after answer delivery.
Withdrawal or correction blocks delivery. The normal private orchestration result
contains original input; provenance metadata is not a claim that the full receipt
is safe for public export. Only synthetic fixtures and bounded summaries belong
in public artifacts; no raw real user/model output is added by this batch.

## What changed, and what did not

- An explicit bounded caller rule can yield an executable conditional premise.
- A responsibility question alone yields an unadopted, non-executable proposal.
- The broad Chinese question “分析人类社会” yields no G01 premise. Running the
  preparer is not a checked substantive analysis of society.
- G01 preparation supplies no actor facts, moral/legal conclusion or responsibility
  verdict. Other source-dependent capabilities remain unavailable without sources.
- Selection still occurs inside the model planner; synthetic scripted selection
  demonstrates wiring only. Real selection quality remains unverified.
- No planner-policy instruction, token limit, provider, retry, research threshold
  or I02–I06 protocol is relaxed. The current inventory advertises G01 readiness; new current requests
  therefore differ from the historical diagnostic request.
