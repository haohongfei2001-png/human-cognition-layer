# I02 — ordinary access and generic map interface repair v2

**CAPABILITY_DELTA:** HCL can now carry a source-reported observation from an
ordinary location-first sentence such as “At the table, he glimpses a key”
when the immediately preceding sentence has exactly one eligible named
subject. It records the exact quote, offsets, observer, object, location,
narrative position and the fact that the pronoun link is a bounded local
interpretation. A direct named observer with `sees`, `notices`, `glimpses` or
`spots` also enters the same checked state. It does not infer private belief,
actual later search, current world location, or a verified pronoun identity.

The [authored positive witness](../reports/HCL_I02_INFORMATION_STATE_V2_WITNESS.json)
saves the actual H and H-new final messages. A later reported move remains in
reader context without overwriting the actor's earlier observation. H-new
keeps the same question, complete source, foundation capabilities and every
other context field; only `information_state` is removed. No extraction call
is made. The [exposed native calibration preflight](../reports/HCL_I02_MUSR_NATIVE_TREATMENT_PREFLIGHT_V2.json)
now finds one exact-span observation and verifies the same H/H-new structure.
This is a **provider-free treatment-presence pass for a previously exposed
calibration item**, not independent efficacy or a paid-run authorization.

The parser refuses a competing non-possessive name in the antecedent sentence,
paragraph breaks, negation, modal/imagined observation, hearsay and missing
location. The pronoun binding is only from the adjacent sentence, never from
global identity inference. The source text remains data. A character-view
projection still withholds reader-only movement. Unit checks cover positive
entry, actor/source/time boundary, uncertainty, negative inference, local
revision and H/H-new composition; 865 v1 and 176 historical tests passed
locally before PR CI.

The consumed C/P/G v1 calibration exposed a separate generic map interface
defect. [A new provider-free G-map candidate](../scripts/serious_eval_arms_v2.py)
now gives its intermediate call an explicit `source_index`/`open_questions`
contract while preserving the complete source/question and the same final
answer fields for C, P and G-final. Its exact-quote validator still rejects
invented source content. This candidate is **UNQUALIFIED** until a separately
designed functional calibration; the consumed first-group run is never rerun.

The [second runtime amendment](../reports/HCL_I02_RUNTIME_AMENDMENT_V2.json)
chains the current digest to the prior I02 amendment without changing I01,
the old calibration package, the old raw receipt or its disposition. The old
one-shot runner now rejects the newer runtime, as it should. Confirmation
material was not viewed, LongMemEval stayed sealed, and this repair used zero
provider calls or spend.
