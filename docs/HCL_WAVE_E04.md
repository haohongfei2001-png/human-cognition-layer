# E04 — Contextual values and conditional partial orders

## CAPABILITY_DELTA

Two different choices can align with unchanged conditional preference statements
when a source explicitly changes the relevant context. Each choice is checked
against its prior source prefix; a later condition cannot rewrite it. This creates
a conditional explanation of changed choice without inventing changed values or
private motives. Explicit preference revision remains a separate native CG04 path.

`prepare_contextual_values` converts only source-grounded literal self statements
and narrator conditions into the existing CG04 checker, preserving original and
derived quotes. Anchored condition updates retire one prior local condition only
for subsequent checks. Ambiguous updates suspend the check. E03 supplies separate
current identity/role views; claiming a role in a preference does not prove role
occupancy. Current role evidence is not a behavior-time or knowledge snapshot.

A bounded directed relation exposes explicit pairs, conditional transitive paths,
incomparable values and cycles. Transitivity is explicitly an analyst assumption,
not a newly inferred self-report. Cycles block a forced total order; opposite
comparisons in different roles stay role-scoped tension. No global value weights,
moral winner, actual motivation or implicit endorsement is inferred.

The simplest alternative is a generic source table with conditional filtering.
Simplify these joins if serious evaluation finds no incremental reasoning utility.
