## Mechanism

`IntegratedScene` maintains separate observer workspaces projected by B02 before
semantic work. Ordinary questions select B01 nested cognition or retained
concept/responsibility/belief composition. Each branch preserves its actual policy,
source binding, check result and uncertainty in a single final model input. Missing
recognized retained task support is explicit `SYSTEM_INSUFFICIENT`; it does not
cause another branch to fabricate a result. Engineering errors and context overflow
still fail the request. Normative premises are routed only to explicitly requested
responsibility checks and remain conditional analyst rules.

A source update validates previously requested observer views before mutation.
Only changed visible text invalidates the corresponding workspace; unchanged
views reuse their prepared result. Prepared input is rejected after source or
support changes. `answer` makes one configured final-adapter call, with no retry
or automatic provider construction.

Narrator records are not people and never automatically enter an actor view. An
explicit receipt of the previous record can make it available. Ambiguous access
cues cannot be reclassified as generic narrator facts. Original narrator authority
and statement-order-only time semantics remain visible. Access does not establish
comprehension or acceptance.
