## Actual implementation

`hcl/cognition/workspace.py` preserves the actual final reader wire payload as a
SYSTEM_INTERPRETATION supported by registered source/version roots. Legacy context
paths retain their prior representation. The complete reader state is preparation
under source/model assumptions, never verified private intention or world truth.
No guessed state is supplied by a test harness or caller.

`OperationResult.current_messages` checks all source versions and dependency support.
`CognitionWorkspace.answer` consumes those actual messages exactly once; no extraction
transport, retries or automatic private-view projection. Receipt currentness includes
semantic challenges, not only version equality. Snapshot bounds are checked before
claims are created; only the explicit source prefix reaches final messages. Source
order remains distinct from event/access/calendar time. The new generic shared path
rejects unbound cross-document identity joins; authorization to read a document is
not character knowledge or proof of identity across documents.
