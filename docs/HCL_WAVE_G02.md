# G02 — Action-time responsibility composition

## CAPABILITY_DELTA

HCL can now compare two people's separate source-reported responsibility
factors under an ordinary G01 caller rule, then check a separately supplied
collective rule against an explicit source report of joint action. Changing
Bob's control evidence leaves Alice's causal/control assessment intact while
the conditional group result becomes unresolved. Harmful outcome and causal
contribution leave knowledge and stated intention unknown unless their own
action-time sources support them. An alternative action is retained as an
actor's report, not silently promoted to feasible world action.

The simpler alternative is asking the base model to compare the two accounts
under the user's rule. Serious independent evaluation after G-ARCH must test
whether this bounded source/time separation improves real outcomes.

## Mechanism and limits

`ResponsibilityCompositionWorkspace` retains one authorized ordinary episode
per actor and an optional separate joint-action report. It uses G01 to parse
the actual user's or explicitly adopted analyst's rule into typed CG03
requirements. A source-reported institution policy or character statement is
not adopted. CG03 checks causal contribution, knowledge, foreseeability,
control and stated intention against each actor's exact source lines using
its focal-episode guard. Later learning does not become action-time knowledge.
The actor's reported alternative must lexically bind the focal action; it
never proves actual feasibility or a better outcome.

The collective condition is a narrow explicit caller sentence: each named
participant must meet the one selected individual rule. A separately visible
joint report must name exactly those two actors and the same reported action;
the individual sources must state the same outcome wording. Matching outcome
wording is a comparison anchor, not independent corroboration. Multiple
individual rules require selection before a collective assessment. Even a
conditional supported result does not establish a group mind, moral/legal
desert, sole responsibility, actual source accuracy or world causation.

The inherited CG03 ordinary parser uses source order and explicit “at the
time” words, not verified calendar times. G02 is bounded to four actors for
individual checks and exactly two for the present collective report grammar.
Source access and record cutoffs are checked before preparation; corrections
and access revocation invalidate saved final model input.
