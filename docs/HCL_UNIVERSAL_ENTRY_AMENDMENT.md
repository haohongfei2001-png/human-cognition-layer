# Universal HCL entry: owner architecture amendment, 2026-10-02

The HCL arm and ordinary user input must enter HCL orchestration on every task.
The system, rather than an external test harness/source regex, decides which
capabilities to select and compose. Complete orchestration does not mean executing
every module blindly or claiming a checked result that was not produced. Base is
an explicitly separate experimental comparator, never an HCL fallback label.
Development remains within human/social/psychological/narrative/value tasks; no
mathematics/physics task expansion or new provider authority follows from this.

## Required stages and evidence

1. Bind complete authorized source, question, source revision and task scope.
2. Understand the task within HCL, preserving an uncertain interpretation rather
   than substituting a developer-chosen task or source/gold-derived route.
3. Select relevant capabilities and dependencies from the canonical inventory.
   Record selected, unsupported and budget-blocked decisions with reasons.
4. Execute selected operations against shared EvidenceCore source roots. Missing
   premises, unsupported grammar, unknown results and failed operations are
   distinct; none becomes a successful empty result or private-state fact.
5. Compose supported results and explicitly unresolved requirements into the
   actual final input. No external Base shortcut when checked results are absent.
6. Answer and review source references, material inference assumptions and known
   capability limits. Preserve raw output, revision fences and real cost/usage.

must be represented as not yet integrated, not silently absent or falsely run.
Subsequent integration can extend this one entry without benchmark-specific routes.

Tests must exercise arbitrary in-scope questions through the same entry, supported
belief/intention/hearing/availability contrasts, the unchanged six MindGames

failure. Assert actual operation counts, source-root dependencies and final input;
assert no Base branch and no forged checked-treatment flag. Replayed historical
experiments retain their historical entry and evidence, rather than rewriting them.
