# Generic narrative event-order development v01

Status: source, generic tool and four-case C/P/T development package frozen; **zero paid authorization**. No source/question/gold text displayed and no model calls. This adds a conditional exact ordering capability, not demonstrated external utility or a new specialized cognition ontology.

## Why this independent direction

CLASH thin value method has no semantic increment and is closed without case fixes. Existing v0.5 valid/record-time separation and v0.6 source/perspective principles motivate preserving event-order uncertainty. `hcl/narrative_order.py` adds a small generic source-anchored strict-before graph: transitive BEFORE/AFTER with proof phrases; UNRESOLVED instead of arbitrary total order; SAME_EVENT identity; cyclic constraints explicitly CONFLICT. Uses standard-library topological sort. Scope supplied explicitly by caller; graphs are separate and cannot silently share edges. Event/reporting order are not equated. No quote-fidelity check can certify an LLM's semantic relation extraction; no true private mental state inferred. Node/edge limits 64/4096; extraction subset later bounded more tightly. No changes to frozen older runtimes.

Provider-free correctness: all 64 three-event directed graphs compared to independently enumerated linear extensions, plus source-anchor integrity, reversed narration, transitive proof, unresolved relations, conflicts and scope isolation. This is conditional tool correctness, not natural-language understanding gain.

## External qualification

[Official TORQUE paper](https://aclanthology.org/2020.emnlp-main.88/) supplies human-written temporal questions over news snippets. Dataset revision `ab27019cc6a317fde3c879900499f02acce8b16d`, dev SHA `7a8dd84c984f28a5284bdfda57b447218e1269cd2eaf05b5e173394fc1522434`, 2,250,044 bytes, 145 passages/1,483 questions. Whole-file format-only check: all 3,502 reference mentions match native half-open character intervals; 123 questions have duplicate surface strings, so string sets would lose event identity. Exact quote occurrence resolves each output to native character spans. Human annotation is passage-relative interpretation, not absolute world knowledge. No event gold, candidate-event annotations, cluster labels or annotated tense categories enter extraction/readout. Test split untouched.

The 2020 paper establishes a temporal-reading benchmark, **not a current-provider gap**. Current DeepSeek alias utility is unknown and must be tested before retaining the tool in downstream use. This development probe is deliberately small and does not establish a stable gap or native score.

Alternatives inspected: NarraBench is a survey/map rather than one scored source; CHATTER full-script attribution adds long-context/resource and trait-interpretation complications; TIMEBench includes latent situational/advice objectives and a paid judge, so its whole benchmark is unsuitable here; TRAM is older mixed temporal data and does not by itself establish current utility. TORQUE offers cheap bounded text/offset evidence for independent event ordering. No claim that it measures every kind of literary or conceptual cognition.
