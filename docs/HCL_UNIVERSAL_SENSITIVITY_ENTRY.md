# Bounded G05 integration into ordinary HCL entry

This provider-free slice exposes the retained `ArgumentSensitivityWorkspace` to
internal selection. Ten of 40 retained packages now have bounded ordinary-entry
adapters. Full integration, model selection quality and answer benefit remain
incomplete/unverified. The retained G05 preparer and its grammar are unchanged.

## Complete source and original caller conditions

G05 takes exactly one selected complete source and the unchanged original user
question. It preserves the source ID, actual ingestion time and shared revision,
including revisions above one. Planner interpretations and actor bindings cannot
supply a hypothesis, premise, reading, priority, timestamp or authority. Source
text that contains a hypothetical is still source data, never a caller request.
Every supplied source, including unselected sources, reaches final answer input.
Separate source operations never combine actor/context domains.

The retained interface accepts one to three distinct single-factor questions:

- An exact argument premise assumed false, with one unambiguous source context.
- One actor using another actor's source-backed local reading of a named concept.
- One actor reversing an explicitly stated source-local value priority.

Each variant starts from the same unmodified base. Variants are not accumulated
into a combined counterfactual. Source-reported fact support can be removed under
an assumption; contested and unsupported premises remain unresolved. A changed
reading or priority does not prove a conclusion flips. Structurally unaffected
paths do not establish true conclusions. No normative framework, world fact or
moral verdict is inferred. Broad, unmatched or ambiguous requests remain explicit
`ADAPTER_REJECTED_NOT_COMPLETED` results; no silent rewriting or Base bypass is
added. Other selected operations can still run, and answer input preserves the
original question and the rejected operation's limitations.

The existing limits remain: 16,000 source characters, 64 lines, 4,000 question
characters, at most three distinct single-factor questions, and a 40,000-character
serialized sensitivity preparation. Oversized source, question or expanded result
is rejected without truncation or a false execution claim. This bounded grammar
is not unrestricted ordinary-language sensitivity analysis.

## Two independent provenance obligations

The shared EvidenceCore claim is a conditional tool result. Its support is one
conjunction containing both the selected complete-source root and a separate
exact original-request root. The latter records request hash and span identity
with `ANALYSIS_CONDITION_NOT_WORLD_EVIDENCE` authority, following G01's conditional
pattern. It is not added to supplied sources or made available as source evidence.
Source-ID collisions are kept separate. Retained line spans remain payload-local;
only the whole source and caller request are imported as shared roots.

Withdrawing either required root or the operation claim blocks answer delivery.
Source correction invalidates the old result; a new preparation uses the new
shared revision without rewriting the old payload. Unrelated source changes do
not invalidate that individual claim, while universal orchestration still refuses
any input-source revision during planning, preparation or answer delivery.

The adapter exposes the current whole-source analyst view. It does not infer
observer access, event/calendar time, historical prefixes or semantic truth. The
direct retained API keeps its existing observer/time/prefix behavior and tests.

## Evidence preservation and checks

Only catalog readiness and ordinary-entry dispatch change in runtime. A new
amendment pins the prior G04 amendment script/report and its complete historical
chain, reconstructs the exact preceding runtime from just those two old hashes,
and verifies the consumed archive chain through v24/DRC008. Existing amendment
scripts, reports, receipts, paid freezes, grants and archives remain unchanged.
Older live witness scripts only advance their current-validator import; their
inputs and assertions are preserved. No historical witness report is rewritten.

The synthetic witness records actual scripted final input, all three independent
variants, source-correction invalidation, caller-request withdrawal and a broad
request's explicit refusal. Tests cover retained equivalence, exact source spans,
versioning, collision safety, source isolation, caller/planner/source authority,
source and request support withdrawal, bounds and tamper rejection. These are
provider-free correctness checks, not model planning or efficacy evidence.
Both historical grants remain closed. This slice makes zero provider calls and
spends zero dollars; it adds no live workflow, provider switch, retry or access.
