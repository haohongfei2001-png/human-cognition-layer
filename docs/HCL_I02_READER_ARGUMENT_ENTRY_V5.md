# I02 reader-level source argument entry, runtime v5

**CAPABILITY_DELTA:** a reader can now ask a bounded ordinary question comparing
publicly reported arguments in a short authorized text. Previously the v4
ordinary entry returned `unsupported_or_ambiguous_question_scope` for this
form. The v5 entry carries the complete source and locally verified literal
speech anchors into the final answer input. It neither infers private belief
nor adopts a conclusion. This is a real input and evidence-preparation gain,
**not demonstrated answer quality or specialized HCL treatment**.

The generic synthetic witness asks for a comparison of two reported reasons,
with an unrelated third speaker retained in the same source. Unit checks cover
full source, exact query, report candidates, source correction, reader/private
separation, normative and unsupported-question refusal, explicit statement
prefix, final-context budget, and historical actor-belief routing. The prefix
test found and repaired a wrapper failure: the source-order receipt now works
with both the older cognition-context shape and the new complete-source shape,
and rechecks the final message budget after adding the scope.

One preselected independent-author [open textbook case](https://brendanpshea.github.io/computing_concepts_python/v2/cases/cs01_lovelace_turing.html)
was used only as a **development entry smoke**. Its pinned publisher HTML and
native question are reconstructed by
[`i02_shea_development_case.py`](../scripts/i02_shea_development_case.py).
Before v5, the ordinary entry refused that question. With v5, its 4,543
character source excerpt and unchanged native question enter final input;
zero literal speech candidates and zero specialized cognition treatment are
reported. No final model was called, so no answer gain is measured. The
[metadata receipt](../reports/HCL_I02_SHEA_CONCEPT_DEVELOPMENT_ENTRY.json) stores
hashes and coverage, not source prose or question text. The author and writing
system are **development exposed** because the implementer viewed the native
question and source sections; they cannot enter unseen confirmation. The page
marks CC BY 4.0, while third-party quotation scope still needs item-level
review; model input is held. Neither a page footer nor a native question alone
establishes full rights, privacy, semantic scoring, or H treatment.

The [v5 runtime amendment](../reports/HCL_I02_RUNTIME_AMENDMENT_V5.json) chains
to the v4 digest without rewriting I01 or consumed I02 packages. Provider
calls/spend: **0 / USD 0**. LongMemEval: **SEALED_NOT_ACCESSED**.
