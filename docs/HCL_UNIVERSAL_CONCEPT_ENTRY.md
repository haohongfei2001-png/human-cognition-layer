# Bounded G03 integration into ordinary HCL entry

This provider-free batch implements the next canonical retained-capability
adapter. Internal planning may now select the existing G03
`ConceptCriteriaWorkspace`. Eight of 40 retained catalog packages have bounded
ordinary-entry adapters. The remaining adapters and model selection quality are
still incomplete/unverified; this is not full A–H capability integration.

## Conditional source-local concept analysis

The adapter takes exactly one selected, complete source. It passes the unchanged
original user question to the retained preparer. Planner rewrites and bindings
cannot supply criteria, facts, equivalences, timestamps or authority. Multiple
sources require separate G03 operations; they are never concatenated into a
shared actor/context domain. All original sources still reach the final answer
input, including those not selected for this operation.

The existing G03 grammar and limits are unchanged: exact necessary, sufficient
and typical rule forms; exact feature claims, applications and equivalences;
explicit matching revisions; 16,000 source characters, 64 lines and 4,000 question
characters. Oversized/unsupported adapter prerequisites remain explicit rather
than truncating input or claiming execution. Unsupported source forms remain
unresolved. A successful preparation may have zero criteria and zero readings.
Neither execution nor the reported counts certify substantive treatment or a
correct interpretation of arbitrary language.

Necessary success remains merely not refuted. Typical matching never entails
application. Contradictory source feature claims remain contested; explicit uses
may be source-reported counterexamples. Same wording does not establish shared
meaning, source claims do not establish world truth, and no moral conclusion is
introduced. Explicit concept revisions retain earlier applications. The adapter
exposes the current whole-source view only: no inferred historical line cutoff,
character access, event time or calendar time. The retained direct G03 API still
supports its separately tested observer/time/prefix views.

## Source identity, revision and support

A temporary G03 workspace keeps the actual shared source ID, complete text,
recorded ingestion time and current version, including versions above one. Exact
quotes, offsets and line order remain in its payload. G03's internal line-span
identities remain local to that retained payload; they are not advertised as
individually imported shared graph nodes.

The complete conditional result is a `CONDITIONAL_TOOL_RESULT` supported by the
selected full-source root in the shared EvidenceCore. This root also covers
absence of parsed criteria. Correcting or withdrawing it invalidates the result;
withdrawing the operation support blocks answer delivery. Unrelated source
changes do not invalidate that individual claim. The enclosing universal request
still rejects any input revision during planning, preparation or answer delivery.
Historical returned snapshots are retained without changing their old versions.

## Evidence and spending boundaries

Only two runtime files change: the dispatch implementation and catalog readiness.
A chained current-runtime amendment pins them while verifying the prior G01
amendment and all unrelated runtime files. Retained G03 code, direct tests and
historical witness remain unchanged. The current inventory changes future planner
requests; the closed diagnostic's frozen request, hash, reservation, grants and
private receipts remain immutable. No provider switch, live workflow, paid grant,
call, retry or new external permission is added.

The new synthetic witness saves actual scripted orchestration/final messages and
source-correction invalidation. Focused tests cover positive and empty preparation,
source-domain isolation, exact versioned spans, contested/revised criteria,
planner inventions, bounds, source and support withdrawal, and partial inventory.
Existing G03 tests retain negative inference, equivalence, actor/context,
ACL/time/prefix and stale-input coverage. These are correctness checks only;
model planner quality, answer gain and independent efficacy remain untested.
