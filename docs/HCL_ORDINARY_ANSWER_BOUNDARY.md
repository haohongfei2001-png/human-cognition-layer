# Ordinary answer source/inference boundary

The existing final-answer contract now asks the model to distinguish explicit
source reports from interpretation, preserve reported causes, identify material
unstated premises in the existing assumptions field, and keep alternatives open
when the cause is not supplied. Useful ordinary inference remains allowed. An
exact action quote does not by itself establish a stable trait, motive or cause.

This is a bounded instruction change in `hcl/cognition/reader_entry.py`, not a
semantic entailment checker. It leaves parser/checker/admission behavior, original
source bytes, output schema, raw output, citation audit and no-retry behavior
unchanged. Source attribution still is not a verified private-state claim. No
blanket refusal or automatic hedging is added. No MindGames item, native label,
stock-story character, title, or unmerged mechanism shapes this instruction.
