## Executed path so far

`literature.analyze` is an ordinary authenticated `ExecutionIssue` goal. The host
partitions every explicitly selected original source into exact Unicode/UTF-8
ranges. One shared graph scheduling step advances one packet. Each response uses
the existing persistent task reservation, governed response object and immutable
source snapshot. A packet repair changes only that packet's attempt identity;
completed prefixes are not resent. A durably RETURNED interruption reuses the
original return after explicit owner recovery. UNKNOWN send prevents resumption.
All packets must compile before the local composition can run or commit.

The versioned fragment proposal supplies frames, events, exact mentions, proposed
chronology constraints, queries, literal motifs and hypothetical edits. Explicit
(fragment ordinal, local ID) references are required. Equal labels do not merge
entities, event clocks, narrators or frames. Unknown links remain unresolved and
cyclic frame ancestry is rejected. Frame/focalization/reliability meanings are
proposed semantics, not established extraction accuracy.

Actual computation currently includes:

- The common exact rational temporal kernel for scoped event-time constraints,
  with separate original-offset discourse occurrences. An event may have multiple
  mentions. Discourse order creates no story-time edge. Different source IDs are
  not silently treated as an ordered chapter list. Refuting `a < b` does not
  establish `a > b`; equal time does not identify two events.
- Bounded exact overlapping literal-pattern scans, punctuation and linebreak
  positions. A mechanical context split does not restart a motif scan. A frontier
  records the checked prefix and unread range; absence is not asserted outside it.
- Explicit DELETE/REPLACE/REORDER variants and recomputed literal form. A
  REORDER is an exact permutation of 2–16 contiguous original pieces from one
  source in the current packet. Its content-preserving offset map projects
  declared mention occurrences only when they remain wholly inside a piece;
  occurrences crossing a cut remain unresolved. Actual before/after/overlap
  comparisons identify changed presentation pairs. Original event chronology,
  source records and character interpretations are not rewritten. Equal surface
  text does not merge two occurrences. The displayed event/frame metadata are
  declared labels, not evidence that the event occurred.
  Generated text
  stays hypothetical, never enters source state or becomes original evidence.
  Emotional, semantic and aesthetic effects of these variants remain unproved.
- Shared M04 residual mechanism search over explicitly grouped local passage
  tasks. The existing M03/M05 or M13 domain adapters produce actual predictions;
  observation targets are not passed to those evaluators. Local packet scope is
  retained for each context. Exact common grammar and search contracts are
  required. All seeds are tested against all passage contexts, so late evidence
  can change the matrix and Pareto set without overwriting earlier cells.
  Equal context display labels from separate packets do not overwrite evidence.
  Nested assumptions, source bindings, frontier and proof limitations remain
  attached to their actual result/context and reach final delivery.

A new packet-local M12 path now executes consistent partial relational mappings,
higher-order constraints, explicit transfer counterexamples and typed term

frontiers reach the narrative answer. This does not complete cross-packet

The answer consumes verified fields of the actual committed operation. It
reports open mechanisms and unmodeled/unresolved material. Reading all supplied
packets is a byte-coverage fact, not a proof of whole-work semantic completeness.
A selected source set cannot establish that external or newly added chapters do
not exist. Model capabilities still identify the built-in offline fixture port;
there is no live transport or claim of model comprehension.

## Resource interpretation

Each scan/temporal closure uses a bounded local batch, sharing the request's local
allowance with comparisons and variants. A scan is capped at 100,000 charged
matcher transitions; an event clock closure at 128 points, 4,096 constraints,
100,000 relaxations and 512 proof edges. These counters are algorithmic bounds,
not a wall-clock or complete CPU instruction count. All original request/context,
return, checkpoint and final-delivery byte limits remain in force. Reorder
generation has the existing four-Mi-code-point source bound, with at most 16
parts and no text expansion. Its occurrence comparison uses a separate bounded
local batch, at most 128 declared mentions and 16,384 charged projection/pair
steps. A zero or exhausted batch leaves named frontier/uncomputed evidence;
source-piece validation and bounded text copying are not CPU-time accounting.
Durable checkpoints intern the original snapshot; reading plans contain ranges, not
repeated whole-book strings. Validated immutable packet plans are not rebuilt
for every packet or carried across new snapshots.
