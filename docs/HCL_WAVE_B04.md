# B04 — Report provenance, conflict and bounded higher-order expansion

## CAPABILITY_DELTA

Three named people repeating one report no longer appear as three independent
supports. Explicit ordinary narration of copying connects their reports into one
provenance family, while preserving each utterance and disagreements inside the
family. A contrary self-report remains a conflict rather than losing to a vote.
Unknown source relatedness never becomes independence. A character's explicit
uncertainty remains different from system missing evidence.

## Running mechanism

`prepare_reports(workspace, question, source_id=...)` reuses A02 source anchoring,
B01 modal trees and A01 dependency/support status. The ordinary question selects
one to three named holders. A third-party reporting wrapper remains a distinct
channel; it does not become the target's private belief. Inner attributions cannot
be detached. Outer denial, uncertainty and non-belief operators retain scope.

A source-local cue such as `Narrator: Kai's last statement repeats Noor's last
statement.` resolves two preceding explicit utterances, with the origin preceding
the copy. Both utterances and the original cue support the relation claim. Reports
with the same speaker and exact modal content are repeated occurrences of one
reported position, not independent acquisitions of knowledge. All occurrences stay
in the receipt. No time-based psychological change is inferred by this operation;
B03 remains the explicit temporal revision operation.

Queries produce report channels, provenance families, preserved conflict/uncertainty,
and actual final model inputs. The number of report families is **not** a count of
independent support; that count remains unknown. No confidence scoring, majority
vote, global trust score or automatic private-state truth is produced. Withdrawing
an origin does not promote copies to new independent sources. Source correction
invalidates old report/relation/family claims before preparing current ones.
