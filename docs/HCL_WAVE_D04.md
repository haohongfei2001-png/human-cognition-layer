# D04 — Misunderstanding localization and revision

## CAPABILITY_DELTA

HCL localizes non-receipt, omitted promise conditions, different local criteria
and self-reported role expectations as separate possible factors. Hearing a
clarification does not automatically repair an expectation. An explicit revised
expectation updates the analyst explanation while preserving the original promise
and the earlier reported expectation. Trust and actual understanding stay unknown.

`prepare_misunderstanding` joins D01/CG02 promise checks, B02 time-specific receipt,
CG05 source-local definitions and A01 interpretation replacement. Concept readings
at the initial expectation use only that source prefix; later definitions are
separate. Meaning differences are possible factors, not established causes. Role
expectations remain the participant's reports, not institutional rules. Clarification
must name the original speaker, recipient, action and unchanged condition. A changed
condition report remains visible but cannot silently rewrite the original promise.
The new analyst interpretation has independent source support and explicit revision
reasons; its replaced predecessor is retained in the core audit.

The simplest alternative is a generic source/expectation comparison table. Post-
G-ARCH evidence should simplify this integration if its selective revision and
source/time handling add no value beyond that baseline.
