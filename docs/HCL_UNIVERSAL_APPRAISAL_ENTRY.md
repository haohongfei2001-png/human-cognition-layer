# Retained C04 appraisal in ordinary entry

Ordinary HCL planning can now select the existing C04 appraisal preparation for
one complete source. The accepted internal question is
`How does <Actor> appraise <episode>?`: one capitalized single-token actor, an
explicit episode of at most160 characters, and a question of at most8,000.
The operation question is an interpretation of the unchanged original task;
it cannot invent a goal, feeling or source fact. Actor bindings are unused.

The adapter calls the native preparer on the shared workspace and validates its
current messages before forwarding its entire payload and all support claim IDs.
That payload retains original sources and versions, source events, native policies,
agency context, current/historical affect evidence, diagnostics and temporal
assumptions. Selecting one source does not remove other supplied sources from
final composition. Source revisions and support withdrawal retain the ordinary
entry's current-state checks before admission and after returned answers.

## Evidence remains separated

Reported feelings, observed expression, third-party judgments and goal-linked
appraisal stay distinct. Mixed goal congruence does not prove mixed felt emotion.
Explicit reappraisal revises its matching anchored appraisal; goal abandonment
changes conditional relevance without erasing the reported feeling. Control and
certainty are source reports, not actual control or knowledge. Generated native
timestamps encode source order, not independently verified calendar chronology.
No observer, historical-cutoff or character-access selector is added.

`checked_treatment_present` requires nonempty native current C04 evidence. This
includes valid expression, attribution, uncertainty and control channels with
their limits intact. Agency-only goals, missing/future goals and unanchored
reappraisal can have support claims while still providing no C04 evidence.
Execution and claim count are not treated as substantive appraisal.

The native row caps remain16 accepted actor literal rows through agency
preparation and20 accepted appraisal source rows. Zero selected sources use the
existing generic source-prerequisite refusal; multiple selected sources receive
the explicit C04 single-source refusal. Unsupported questions and native bounds
remain rejected operations. Native parsers and grammar are unchanged.

## Complete transport and local evidence

The complete source and result must pass the existing serialized DeepSeek request
bound of36,000 bytes. No request, payload, source or evidence is truncated. Tests
use the real local request validator inside a provider-free port: an oversized
complete source stops before planning, and three complete appraisal operations
stop before the answer invocation when their combined request exceeds the bound.
The generic HCL interface and provider/model/token configuration are unchanged.

The scripted positive witness preserves the original question and exact original
source citations. Its initial complete requests measure20,921 bytes planning and
16,862 bytes answer. After an explicit goal revision they measure20,984 and17,827.
These measurements belong to the recorded synthetic witness; any future live
package must freeze and reserve its own complete requests. They do not establish
model selection, semantic correctness or answer improvement.

The amendment preserves all126 historical artifact pins and proves that removing
only the added C04 contract and dispatch restores both prior runtime files
byte-for-byte. Whole-runtime restoration also preserves native appraisal,
agency, source-scope, B04 and transport implementations. The frozen validation
receipt distinguishes local checks from the unchanged hosted publisher-byte gates.

B04's native six-line message remains42,660 bytes; its ordinary adapter still
requires a separately reviewed complete evidence representation. This slice does
not silently trim that graph or activate B04. The next canonical composition work
is C05, preserving action-time evidence and shared lifecycle semantics. All paid
grants remain closed; no new provider call or spending authority is created.
