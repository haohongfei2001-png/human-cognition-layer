## Current direction

Select **evidence-constrained conflict and argument acceptance** as a narrow
conceptual/philosophical reasoning building block. This evaluates how an
objection, a rebuttal of that objection, or a cyclic dispute changes a
conditional conclusion. Reuse EventRecord, access, chronology and provenance;
keep alternatives/undecided labels and do not create a value hierarchy.

[DeReLab](https://arxiv.org/abs/2608.30413) reports multi-turn defeasible-update
failures on recent model families. It uses PMPM default/inheritance semantics,
which are not interchangeable with Dung argumentation. No DeReLab graph/gold
is repurposed as an oracle for this candidate.
[Enhancing Conflict Resolution via Abstract Argumentation](https://arxiv.org/abs/2412.16725)
studies grounded/complete argument labellings and published formal reasoning
errors. Its author repository at revision
`7a0cf15337dfab91d144331e88880a434d7120a0` supplies generator code, but no
released non-vendor JSON/APX dataset was found in that tree; no root dataset
license identified. It is motivation, not an available external test set.

These studies do not verify a stable deficit of the current deepseek-flash
alias, nor show that abstract graph acceptance solves real moral debate.
This minimal candidate tests that prerequisite cheaply before any larger work.
Relationship/affect stay deferred or simplified; natural-language argument
mining, subjective values and full philosophical judgments remain outside scope.

The candidate uses ordinary published Dung semantics and exact enumeration,
not a new cognitive theory. A competent generic executable implementation has
the same mathematical output. Compare prompting to one generic-tool arm through
the source-bound wrapper; avoid duplicate paid D/G arms. If prompting is enough,
simplify and leave this candidate. If a small increment appears, a future
source-qualified disjoint comparison still needs real external coverage and a
separate owner protocol/cost approval. No later version sequence is fixed.
