# I02 blind source-first review handoff

**State:** provider-free reviewer handoff implemented; **no blind semantic judgment has been collected**. The next work remains genuinely unexposed source qualification and competent C/P/G review. This packet machinery does not turn the exposed ACL exercise into confirmation or establish HCL answer gain.

`scripts/i02_blind_review_packet.py` takes an immutable source-first obligations manifest and a completed raw provider receipt. It verifies the rubric, exact source binding, final JSON contract, exact citations and normal completion before generating a reviewer packet. The packet contains the authorized source, obligations and final answers under unpredictable opaque IDs. It omits arm names, G-map, requests, reasoning traces, model IDs, usage and costs. A separate allocation key maps IDs to arms; give **only the packet** to a reviewer who has not seen the raw receipt or key. Access to the public repository itself is a procedural blinding risk, so this tool does not certify that a particular reviewer remained blind.

The CLI requires explicit `--manifest`, `--receipt`, `--phases`, `--packet-output` and `--allocation-output` arguments. It refuses to overwrite either file and writes the separate allocation key with owner-only file permissions. The real ACL receipt was exercised with C, P and G-final and produced three opaque outputs; that local packet is a functional witness, not a submitted blind review.

After every opaque answer has a complete `hcl-i02-blind-review-v1` judgment with source or output excerpts, `reconcile_reviews` checks exact packet, manifest and allocation commitments and runs the frozen semantic scorer. Only then does it return scores by arm. Missing, duplicate, edited, source-invalid or phase-labelled reviews fail closed. The code never decides whether a semantic judgment is true. Unresolved judgments earn zero under the frozen rubric. A reviewer who already saw arm identities cannot produce qualifying blind evidence by rerunning this tool.

The positive test uses the real ACL v8 receipt to show three final C/P/G outputs can cross the handoff boundary while the intermediate G map and provider traces stay outside. Negative tests mutate the source, citation, packet obligations, allocation and review completeness. Historical scorer and ACL freeze tests still pass. This is **review-process correctness**; no new provider call, spend, confirmation item, H/H-new result or LongMemEval access occurred.
