# S3 conditional appraisal and coping increment

This is a bounded M08 composition through the ordinary authenticated HCL entry.
It is partial offline evidence, not completion of M08, T10, T19 or S3. The
approved S1–S7/M01–M16/T01–T32 research exits remain unchanged. Injected candidate
interpretations provide test conditions; they do not prove extraction, semantic
alignment, completeness, human emotion calibration or private mental truth.

## Actual computation and consumption

`affect.evaluate` compiles `hcl-affect-candidates-1` into the common executable
LocalModel protocol. Source spans bind every proposed goal consequence, mapping,
coping mechanism, episode and report. Question spans cannot supply facts and
candidates cannot supply appraisal values, Q, emotion results or coping scores.
The existing M03 model supplies real event-product perspectives at each episode's
before/current times, separately from designated-world possibilities. Exact
source versions, actor/time, active assumptions and variable/result identities
remain attached to those actual views. A late event cannot backfill an earlier
appraisal. A withdrawn assumption or world/resource frontier does not fabricate
a later view.

Each goal has an explicit finite consequence function. Its previous/current
values are computed over the actual supported states. Declared probabilities
produce exact rational expectations. With no distribution, all possible values
remain an interval; counting worlds never silently creates probabilities.
State change is separate from expectation gap: the latter requires an explicit
prospective action transition from the earlier perspective. A previous state is
not relabeled a forecast. An explicit forecast that lacks a feasible opportunity
propagates FORECAST_OPPORTUNITY_UNRESOLVED and PARTIAL, whereas an explicitly
absent prospective model retains NO_PROSPECTIVE_MODEL. Without a cross-time joint distribution, interval
differences conservatively retain all compatible changes.

For each goal and supported state, the actual M05 solver computes action Q and
opportunity information. A favorable Q is not control when the action is
infeasible. Subjective availability/feasibility, possible/robust improvement,
and designated-world feasibility remain separate. Competing source-declared
semantic mappings use three-valued predicates over the calculated appraisal
and prior conditional hypotheses. Mixed goals can support competing affect
interpretations. A reported smile or sadness does not assign a private emotion.
Self-report, observed expression and third-party attribution are separate source
channels, not evidence that an inferred psychological mechanism is established.

Coping alternatives specify goal priorities, appraisal-conditioned priority
multipliers, considered actions, optional observation coarsenings and a finite
planning horizon. An override must map each original observation class to one
new class; it may merge or rename classes, but cannot invent a finer sensor.
A genuine information-gathering action needs an explicit source transition and
observation model. The same calculated appraisal changes normalized priorities;
the resulting consequence function is solved by actual M05. Unknown conditions
retain both branches. Disconnecting the appraisal adjustment changes the actual
Q results in the witness, rather than only changing a displayed emotion label.
Problem-focused/avoidance/reinterpretation/support-seeking tags remain proposed
semantic descriptions of these explicit mechanisms, not independently certified
psychological categories. One-step successor distributions then produce new
hypothetical per-goal appraisals. They never become actual M03 events or enacted
coping. This increment compares bounded alternative mechanisms; it does not
claim a calibrated continuous emotion/behavior process.

## Reappraisal, qualification and limits

Versioned episodes refer to an earlier version of the same actor and episode.
New-information revisions cannot silently change the goal/coping theory or
transition model. Goal revisions and analyst alternatives are explicit.
Changed dimensions are recomputed; unchanged dimensions remain visible. New
state/variable identities are retained as evidence changes without falsely
claiming a changed appraisal when all consequences and opportunities are equal.
Analyst alternatives explicitly do not establish character reappraisal. All
other reappraisal claims remain conditional on the source model.

The consumer independently reconstructs the M03 perspectives and verifies every
consumed view, state mapping, goal-specific Q, priority transformation, coping Q,
successor appraisal, version difference, assumption environment and hypothetical
qualification. The full composed result is immutable in the store; compact
claims reference exact fields of that committed result and its nested M03/M05
values. ACL and source-version gates apply through final delivery and cached
replay. RETURNED/computed/committed recovery does not resend or replace accepted
operations; UNKNOWN occupancy remains unknown.

There are at most eight models, sixteen ordered versions per model, eight goals,
eight coping alternatives, four priority rules and sixteen possible branches,
thirty-two semantic mappings and thirty-two planning states. M03/M05 limits and
the shared local-work/output budgets remain authoritative. A valid derived
zero-total priority branch is undefined, not a fabricated uniform priority.
Derived rationals outside the existing planning numeric envelope retain a named
frontier rather than being rounded or misreported as invalid input. Missing
probabilities, partial cognitive views and finite work exhaustion propagate to
PARTIAL output with visible limitations. If subjective planning is computed but
a different designated-world plan reaches its budget frontier, subjective
appraisal survives while actual feasibility stays unknown with its own frontier.
Parameters are conditional inputs, not
fitted psychological measurements.

This uses the appraisal/interpretation distinction discussed in Marsella and
Gratch, “EMA: A process model of appraisal dynamics” (2009), as a design influence:
https://stacymarsella.org/publications/pdf/EMA_Dynamics.pdf . The explicit finite
models here are not that paper's full model and are not human psychological laws.

Attribution, normative/identity relevance, calibrated temporal affect dynamics,
a richer affect-to-coping search and semantic category validation remain open.
Those profile dimensions say NOT_MODELED, not zero blame/relevance. Full M08,
M09, cross-domain S3 integration and all remaining approved research requirements
stay in the formal plan. Historical A–H/G-ARCH evidence is not promoted by this
increment. Provider calls, spend and sealed reads are zero.
