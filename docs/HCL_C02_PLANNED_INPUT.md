# Planned structured input for the existing C02 tool

The model may now use the same first planning response to translate ordinary
source wording into C02's existing structured action-explanation input. This
extends the earlier B01/C01/C03 bridge; it adds no capability package or parser.
Fixed structured inputs are normal tool contracts. The integration supplies
those inputs while keeping the model's interpretation distinct from evidence.

## Bounded execution and provenance

At most one selected B01/C01/C02/C03 operation receives `semantic_candidates` for
one complete source. The existing 24-candidate bound remains; C02's lower native
20-row and two-supported-goal limits still apply. Exact source-named ASCII actor
labels of at most 32 characters remain required by the conditional mapper. No
alias, source identity, speaker or source quotation is silently invented.

The retained adapter validates original quotations, builds the explicit derived
representation, and runs unchanged `prepare_explanations` on it. The full native
result, policy and source order remain within a conditional state. Original
source IDs, revisions and quotations stay outside that derived state as the only
quotable evidence. Projected tool results depend on their source and model
translation assumptions; withdrawing either prevents answer delivery.

The initial planner call already paid for producing the candidates. A local
single-use replay object supplies those candidates to the existing preparation
interface, so no additional provider phase or hidden extraction call is added.
The sequence remains planning, native HCL execution, answer and original-citation
review. No-candidate calls retain the original direct C02 interface.

## Preserved meaning and negative controls

Competing supported goals remain nonexclusive explanations. Explicit knowledge
negation and opportunity conflicts stay visible; missing evidence is not negative
evidence. Later knowledge or goals cannot backfill action-time prerequisites.
Explicit negated actions use the native choice forms, and non-action alone does
not imply inability. A repeated matching action remains ambiguous rather than
selecting an older or newer occurrence.

The native tool still returns `winning_motive: NOT_INFERRED`. None of its derived
checks proves the model interpretation, a unique actual motive, private belief or
world truth. A native insufficient result may inform a limited answer without
becoming positive treatment. Candidate-list order cannot rewrite source order.

Regression controls cover competing goals, knowledge/opportunity negation,
conflicts, later evidence, other actors, repeated actions, malformed queries,
native row bounds, original-source citations, revision and withdrawal of both
candidates and projected translations. Complete request overflow stops before the
answer call without dropping candidates, native output or source material.

## Actual engineering evidence and remaining delivery work

The witness sends authored ordinary prose through a scripted first model
response, actual C02 execution and a cited final answer. A source revision changes
the conditional result and invalidates the old support. These are complete
offline interface checks; they do not establish real-model interpretation quality
or improved answers. Exact captured source snapshots, request bytes, hashes and
conservative reservation measurements are in the matching witness and validation
reports. Production token defaults and the 36,000-byte request bound are unchanged.

The conditional-input bridge now covers B01, C01, C02 and C03, with one translated
operation per request. Other families and unsupported representations remain
explicit. After this demonstrated integration gap is closed, breadth extension
pauses in favor of consolidating end-to-end readiness and a separately authorized
real-model delivery check. Real private-result readback and model quality require
their own evidence. No provider calls, new keys or historical rescoring occur in
this source change; all historical grants remain closed.
