## Approved artifact and independent result review

The public artifact contains one strictly whitelisted original closing receipt
and at most one bounded native record, with no duplicate native bundle. The
receipt contains call/budget state, one returned final answer when present,
bounded code/stage, capability IDs/counts, request sizes/hashes, capture status,
timestamps and same-run admission hashes. It does not separately copy raw source
payloads; source quotations within the approved final answer remain intact. It contains no full plan,
native output, provider envelope, account balance or credential. The native
record contains source-validated actual arguments/results and source binding,
at most three operations and 1 MiB. Only the original HCL repository is an
approved destination. Full planner content, hidden reasoning and private data
are excluded.

The runtime diagnosis reaches disk before optional native capture. Checked
ordinary closing evidence is exported first, so a failed native projection
cannot erase the diagnosis or known accounting. Corrupt ordinary evidence yields
only a fixed integrity-unavailable, no-resume closure with unknown counts/costs;
it does not invent a diagnosis, usage or refund.

An in-memory evidence view is derived from the public artifact. Complete native
capture can be reconstructed from its single projection and checked against the
original receipt hash. A success review must also match independently retained
original receipt/capture bytes; self-consistent substituted public data is not
enough. The independent source-first review evaluates the unchanged ten answer
obligations and four smoke requirements, native relevance and delivery. Correctly
bound failure evidence remains failure. Hashes do not authenticate originals if
the caller replaces both the originals and their separately trusted anchors.

The permission and preparation package are not a result. Real call count, usage
estimates and closure are reported only after the single authorized invocation.
