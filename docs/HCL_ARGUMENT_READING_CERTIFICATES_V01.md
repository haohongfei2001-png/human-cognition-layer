# Explicit argument-reading certificates

Provider-free correctness instrument; **no externally demonstrated cognition increment** and no paid experiment authorized by this document. Reuses the existing bounded formula parser, finite countermodel verification and full first-order equivalence tool. Independent HCL implementation; no FOLIO text, labels, native formalizations or consumed-case rules are runtime/test inputs.

`hcl.argument_readings.classify_reading(premises, conclusion)` checks consistency before entailment/refutation. All results are conditional on caller-supplied formal premises, ordinary nonempty-domain classical FOL, co-referring names allowed. True means entailment, False means entailment of negation, Uncertain means both possibilities established; solver UNKNOWN is a separate unresolved status. Contradictory premises produce INCONSISTENT_PREMISES without an explosive True/False label. Equivalence compares the premise conjunction with itself conjoined with conclusion or negation; finite witnesses refute equivalence, but failure of finite search never proves full entailment. The full-FOL fallback can time out and remains unknown.

`compare_readings` takes one to four explicit interpretations, each with distinct id, the same declared source SHA256 and formal premises/conclusion. It preserves individual consistency, entailment/refutation results and formalization digest. Agreement is **only across supplied readings**, never evidence that all NL interpretations were generated or that source truth was established. Different classified labels yield READING_DEPENDENT, with no chosen winner. Any inconsistent, unknown or conflicting solver result yields UNRESOLVED_READING, preserving each result. The supplied source hash is a caller assertion, not automatically verified against source bytes; caller must audit provenance and translation fidelity.

Limits: one to16 premises per reading, 4000 characters per formula, combined512 AST nodes, one to4 readings, per equivalence call timeout1..2000ms (default500); three equivalence checks per complete reading, bounded finite preprocessing plus full-FOL solver. These are per-solver limits, not a wall-clock service-level guarantee. No automatic NL translator, gold/native parser, paid judge, new ontology or model request. No world/private-mental/moral truth claim. Examples/tests concern generic implication chaining, explicit counterexamples, open-world possibilities, conjunction/disjunction alternatives, contradictory assumptions, named-constant co-reference, timeouts, provenance and size limits.
