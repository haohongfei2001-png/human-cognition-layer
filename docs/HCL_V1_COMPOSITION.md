# Composition of existing scoped cognition operations

## CAPABILITY_DELTA

One ordinary narrative can now support one final answer that jointly explains
expressed contextual preference, speaker-local concept meaning and a conditional
responsibility basis. Previously these were mutually exclusive request operations.
The integration executes their existing mechanisms separately, then presents the
actual checked states together. It does not infer bridges from "fair" to value,
from preference to intention/control, or from a source claim to moral truth.

`answer_composed(layer, question, (responsibility_request, preference_request,
concept_request), debug=True)` performs one final adapter call and zero extraction
calls. Two or three distinct existing CG03/04/05 requests must share exactly the
same source, focal actor, observer and time scope, with identical perspective.
No automatic module activation, formal tools or persistent injected state.
Ordinary composition is reader analysis; private views require common validated
EventRecords. Operation-specific access remains distinct and cannot be borrowed.

Provider-free grammar integration now recognizes a complete other-operation
statement without treating it as its own: a CG04 rain condition is not a CG05
object property/narrator application, and a concept revision containing "instead
of" is not a malformed preference. Exact own-domain malformed input still fails
closed. The frozen default CG04/05 cases and all final messages are unchanged.
Frozen replay uses old certified runtime; no prospective fix migrates a grant.

An operation's uncertainty remains visible alongside working operations. A total
budget overflow rejects the whole joined context without picking a misleading
subset. Existing lossless encoding is optional and fully auditable. Actual final
messages, prepared stages and preparation-only counters are preserved. Each stage
executes no answer call; the joined answer has one adapter call. Receipts are
engineering evidence; actual new paid calls/spend are zero.

Ten tests cover ordinary three-operation execution, local counterexample/revision,
foreign grammar separation, partial failure, mixed actor/source/view refusal,
private typed views, hidden condition/property IDs, duplicate operation rejection
and total-budget failure. No broad model-utility claim or new candidate/module.
CG04 and CG05 remain the only two deferred implemented-unvalidated candidates.

Private ordinary composition can now opt into exact narrated access with
`narrative_access=True` on every operation; see HCL_V1_NARRATIVE_ACCESS.md.
Without that opt-in, shared validated typed EventRecords remain required.
