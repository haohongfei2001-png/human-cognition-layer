# F05 — Multi-chapter narrative replay and branch comparison

## CAPABILITY_DELTA

HCL can now answer a named-person question over several authorized chapters and
separate story paths at a specified story, disclosure and analyst-record cutoff.
It surfaces opposed same-day reports from distinct sources with both exact
quotes and their complete recorded F03 support pair. It compares alternate
branches as different possible story paths, not as one contradictory world.
After a source correction, the current conflict can disappear while an earlier
analyst-record view remains inspectable. A user can optionally select one F04
action-change comparison inside the larger replay, with the same time and
authorization boundaries.

The simpler alternative is sending all chapters to the base model. A later
serious independent evaluation must test whether this source/time/branch
projection is worth its cost and complexity.

## Mechanism and scope

`NarrativeCorpus` reuses F02 chapter versions and temporal axes, F01 exact
event references, F03 evidence closure, and F04 rival development explanations.
The caller supplies a chapter's branch as provenance metadata; no mental state
or correct interpretation is prefilled. The result keeps names source-local.
Matching “Mira” across chapters is an explicit conditional same-surface
hypothesis, not proof that all chapters concern one person. An opposed report
is a source tension, not proof of actual belief, world contradiction, lying or
unstable personality. Same-day suborder is unresolved.

The replay selects all authorized named events in one branch and time cutoff;
it does not infer a character's access from the analyst's access. F02 carries
challenge and receipt distinctions. Source revisions and current access
revocation invalidate the appropriate final model input. An unrelated branch
does not invalidate a selected branch. The operation refuses when the selected
person, conflicts, or final context exceeds its budget; it never silently
drops a conflicting source to fit the model input.

## Provider-free verification

Eleven targeted F05 tests cover ordinary multi-source conflict, F03 closure,
three temporal slices, late contested recollection, separate-branch divergence, source correction and
historical replay, access revocation, unrelated-branch non-interference,
other-actor and pronoun boundaries, F04 composition, and event/conflict/context
budget refusal. The ordinary witness saves the actual final model messages in
`reports/HCL_WAVE_F05_WITNESS.json`.

A deterministic scale smoke generated 12 chapters, 12 named active actors and
120 dated events, totalling 189,280 characters and 20,880 whitespace-separated
words. Three slices returned 3, 6 and 10 events for the selected actor. This
is an engineering capacity check, **not** tokenizer-certified 20k–40k tokens,
independent long-form comprehension evidence, or a provider result. The witness
records source hashes, event counts and the selected actual model input.
